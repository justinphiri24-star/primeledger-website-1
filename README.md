# PrimeLedger Financial Service Ltd. — website

Static one-page website for PrimeLedger Financial Service Ltd., Lusaka, Zambia.

- `index.html` — the page
- `styles.css` — styles
- `assets/` — logo, header mark and favicon

No build step. Open `index.html` in a browser, or host the folder on any static host
(GitHub Pages, Netlify, cPanel, etc.).
